# 1.0.5：分阶段体验流程

2026-11-26。包名 `com.example.spacebend`，versionName 1.0.5、versionCode 6。

## 实际操作路径

主页选择自由体验或挑战；尚未完成本次空间确认时进入扫描，完成后直接进入所选模式。绘制阶段明确提示第一洞、还需要几个虫洞及可进入选物的条件。自由体验至少2洞；挑战沿用本关最低洞数。

选择物体时以选择面板替换绘制面板。图标和名称都可点击；底部固定“发射＋物体名”与“返回绘制”，适配检查明确指出过小洞口。只有点击发射按钮才启动，面板外扳机不再隐式发射或画线。

运行阶段显示循环次数和停止操作。主动“停止并调整”保留虫洞、累计时间与碰撞记录；清空重画才清除布局。碰撞仍触发原来的虫洞收缩消失，自由模式直接回到绘制，不出现失败/星级面板。挑战保留结算，结果出现后尚未落地的物体继续落地，稳定循环也可继续显示。

教程嵌入当前步骤，并依据实际绘制、发射、传送和循环推进，不再叠加一个独立教程窗口。菜单和设置临时暂停模拟；返回时恢复工作步骤与布局。另开非空实验会明确确认清空当前布局。

## 面板和跟踪

`currentPanel` 是唯一任务状态，兼容的 `panels` 集合由它派生；SceneRuntime只启用相等的附件。保留既有Mixed Stage及8个附件ID，教程ID不再进入独立显示流程。各工作页共用960×640dp尺寸和0.86米适配宽度；拖动当前页后，其余工作页沿用相同工作位置。

重新扫描会重启官方平面订阅、等待新数据再允许继续。按UUID保留SurfaceAssembler坐标基，避免重新三角化导致已有虫洞旋转；只有真实REMOVED事件删除基。短暂跟踪丢失会暂停并恢复原步骤。锚点确实失效时，界面告知需要清空重画，点击明确的重画按钮才清除失效布局。

保留1.0.4的平面网格缓存、分帧轮廓构建与共享资源所有权修复。未更改Spatial SDK/BOM、重力、传送顺序、碰撞几何、12关评分或持久化结构。
